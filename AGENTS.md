# Monorepo

- **No noise.** One fact per bullet. Principles only — not implementations, filenames, or the change you just made.
- **Redundancy:** Do not repeat a write the owning path already performs. A later step in the same turn uses the id already in hand. Do not hunt a second copy of the world. Do not add a cache or fallback chain to cover a duplicate write. A pass that still has a job at that point in the loop is not redundancy — keep it.
- **pnpm** workspaces + Turborepo. Run pnpm directly. Root: `pnpm dev`, `pnpm build`, `pnpm check-types`, `pnpm lint`.
- Apps: `root` 3000, `accounts` 3001, `shop` 3002, `support` 3003, `api` 4000. Packages: `ui`, `auth`, `db`, `api-client`, `contracts`. Tooling: `typescript-config`, `eslint-config`.
- **Done:** `pnpm check-types` (or the covering `tsc --noEmit`) before you stop. `check-types` and `dev` depend on `^build`.
- **Built vs JIT:** `@repo/contracts` is built (`tsc` → `dist/`). Not JIT. Not in `transpilePackages`. JIT for Next: `@repo/ui`, `@repo/api-client`.
- **Install:** `pnpm add` / `--filter` / `-w`. Latest stable unless already pinned. Never hand-edit versions.
- **Imports:** static only. The call site names the contract. Env is `@repo/db/env`, not `@repo/db`. Contracts from `@repo/contracts` at the call site — no redefine, no re-export. API: `@api/…` + `.js` (no `../`). Groups: side-effect → external → workspace → `@api/…`. Inline `import type` on a shared module. Next: `@/*`. `api-client`: bundler, no `.js` on relatives.
- **No comments in source.** Put rules here or in `.env.example`.
- **Docker:** agents do not run Compose unless asked. `apps/api/.env.local`. Postgres-only: `pnpm docker:postgres`. API in Compose: `pnpm docker:up` (runner) | `pnpm docker:dev` (watch target + `--watch --build`). `pnpm docker:down` | `docker:logs` | `docker:ps`. Container entrypoint migrates when `RUN_DB_MIGRATE=true` (default); empty DB also runs `pnpm db:seed`.
- **Browser:** Do not open or drive the app in a browser unless asked.
- API: Express 5, tRPC v11 `/api/trpc` `v1.*`, thin `modules/*/`, no Express in tRPC context, `AppRouter` from `@repo/api/trpc`, `@api/*` → `apps/api/src/*`.
- Zod 4: `z.url()`, `z.iso.datetime()`.
- Client: `@repo/api-client`. `NEXT_PUBLIC_API_URL` required; Next rewrites `/api/:path*`.
- Better Auth `/api/auth/*` before `express.json`. Identity only; authz in procedure guards.
- Env: `requireEnv` / required `NEXT_PUBLIC_*`. `.env.local` then `.env` (neither overrides already-set process env — Compose `DATABASE_URL` wins in the API container). Copy `.env.example` → `.env.local`.
- Root does not call Accounts/Shop/Support mutations.
- DB: Drizzle + Postgres. `packages/db` by owner. One database is not shared authority. No cross-domain joins. Support stores owned copies of customer and order text, never Shop or Accounts tables. Domain rows are server state, not in-memory fixtures. `pnpm db:generate` then `pnpm db:migrate`. No `db:push` without explicit consent. No ad-hoc SQL. Empty `returning` is not success. Auth seed: `pnpm db:seed`. Provider seed: `pnpm db:seed:providers`. Do not run provider seed unless asked.
- Queries: filters in SQL `WHERE`. One round-trip. One JS pass (`flatMap` / `for…of`), not `.filter().map()`. Readable names. `Pick` / `Omit` / `z.infer`.
- **Ternary:** One condition. Nested or chained branches use `if` or a named helper.
- **Props:** Omit `className` unless a caller passes it. Then extend `ComponentProps` of that element (or `Pick` `className`). Never invent `className` or extra `children` on `ComponentProps`. `PropsWithChildren` only when the base type has no children.
- **Commit:** Layout effects run inside-out. A child's layout effect runs before the parent host ref is filled; the parent node is already in the DOM. Do not read a parent ref there. Measure from this node's ref or the DOM parent. A layout effect does not beat the first HTML paint.
- **Same turn:** A handler runs before layout effects and the next render. State and refs that sync after that commit still hold the previous world. That staleness is the cycle, not a reason to drop the ref. A later call in this turn that needs this write already holds the result; it does not ask that world. Think through the cycle before treating a post-commit snapshot as current.
- **Motion:** A known first-paint rest is CSS on one fixed origin. Gesture, snap, and resize are offsets from that origin. Do not switch the origin; that redefines the offset and jumps. Do not pin first paint with JS. Open, close, and yellow minimize pour one temporary presentation into the existing Dock mark while the live document keeps its stage geometry; restore reverses it, and reduced motion is instant. Green fullscreen stays instant, including yellow minimize and restore from that fill. Agent-triggered open, minimize, restore, and close skip that pour; a human still pours, including yellow from a green fill. A labeled chip that fades and shifts on Y: opacity is fine; CSS `transform` translate on that face shimmers the type (GPU subpixels). Motion `y` is the same path. Offset with margin, not translate.
- **Presence:** Keep exiting geometry long enough for the parent to interpolate size from one fixed layout anchor. Exit one presentation snapshot together. Brief state gaps preserve the surface; only sustained absence collapses it.
- **Scale:** `@repo/ui`. Headings `text-3xl`. Body `text-base`. Labels `@repo/ui/label`. Controls `h-8`. Buttons `rounded-3xl` and hug the label. Primary or destructive; no outline; ghost only with a visible gray hover. Heroicons `24/outline`. `data-app` remaps `primary`. Root is a Mac desktop: full-viewport canvas, pinned Dock, persistent independent provider windows, one workflow status that rests as a Root mark, grows a pill while work runs, turns red on failure, and springs to the nearest canvas corner. Steal spatial rules, not Apple chrome. Green fills the canvas; green again restores. A window may hang off the canvas and sit under the Dock; the titlebar stays grabable. Dock marks grow out of the shelf; the tray does not swell with them. An empty pin list keeps that shelf at rest tile height; width hugs. A Dock click rests magnification with a hop; pointer movement resumes it. The app library owns providers; the Dock owns ordered references. Builtin providers mount. Child pages are a dark canvas in that hue, not the ink fill. Inter sans; Geist Mono for `font-mono`. Library jiggle exits on empty wallpaper; empty means the click did not hit a mark, the Dock, a window, or the Root inspect.
- **Workflow:** Prepare freezes an allowlisted graph. Search, open, and create are legal; it refuses illegal tools and arguments, not useful length. Repeats of an allowlisted tool are legal. The step cap is a safety ceiling, independent of how many children or tool names exist. Create writes only after a human persist on stage; tray create refuses. Execute opens or reuses each provider window, rediscovers, and invokes each step on that live document without closing the others. A later step’s argument may be a bind; execute delivers the earlier selected snapshot intact; an open id bind uses that snapshot’s sourceId; Root does not flatten it. Do not add a per-app prepare function. Custom invoke is a separate Root tool on a human grant; it never enters pass evidence. Agent lease is per window: the same window serializes; another window stays free. A leased document is shielded until Take control. Take control is `stopped_by_user`; do not retry. A pending-on-human wait with no gesture resolves `no_response`, not `stopped_by_user`. Agent window chrome is tools on the same yellow / green / red paths; close is not task cleanup. A passed workflow does not auto-minimize; the agent yellows if it wants the tray. Close stays explicit. (Auto-minimize after pass is parked, not removed.) Live documents have a soft cap; eviction is silent close of agent-opened windows, never human-opened or focused. Rich DOM (highlight, scroll, fill, preview) only on stage; tray stays the plain tool path. Agent fill of a visible input is the interaction owner, stage only. A human edit to that field is the submitted value once they click that control; Take control still aborts; the pill parks so it does not cover the field. Preview of the control about to fire is the interaction owner, stage only. A row click on the live list is the pending-on-human choice; Take control still aborts; the ask sits on the document. The inspect names the waiting provider; its Dock mark lights only when that window is in the tray or unfocused. The pending-on-human window rises; the others stay live. The agent-pointing mark is a still silver halo behind the face, not the focus ring and not the Take-control spin. Provider interaction has one owner; search pages do not grow presentation effects.
- **Rich DOM:** When a builtin provider gains a capability, propose how that action presents on stage in the same pass. The interaction owner runs it. This is the default for agent-visible work, not a special case.
- **Tests:** Lock practical behavior at its boundary. Do not assert descriptions, labels, assigned literals, or static wiring that merely restates source. Do not write or rewrite a test whose only job is restating source. Do not extract a module so such a test has a home. Exact text belongs in tests only when parsing or an external contract depends on it.
- **Validation:** Validate once when untrusted data crosses a boundary, retain the typed value, preserve byte limits before JSON parsing, and measure before adding validation caches.
- **Errors:** A gateway failure throws `GatewayError` with the envelope code already set. Catch uses that code. Do not recover the code from `message` or `name`.
- **Opaque failures:** When the live agent envelope cannot name the failing phase, put that phase in the bounded error message so the next tool result can. Dev only. Stay within 280 characters. Production stays generic. That envelope is the log; do not invent a test to stand in for it.
