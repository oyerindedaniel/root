# Monorepo

- **No noise.** One fact per bullet. Principles only — not implementations, filenames, or the change you just made.
- **Redundancy:** Do not repeat a write the owning path already performs. A second call that only duplicates that owner is waste. A pass that still has a job at that point in the loop is not redundancy — keep it.
- **pnpm** workspaces + Turborepo. Run pnpm directly. Root: `pnpm dev`, `pnpm build`, `pnpm check-types`, `pnpm lint`.
- Apps: `root` 3000, `accounts` 3001, `shop` 3002, `support` 3003, `api` 4000. Packages: `ui`, `auth`, `db`, `api-client`, `contracts`. Tooling: `typescript-config`, `eslint-config`.
- **Done:** `pnpm check-types` (or the covering `tsc --noEmit`) before you stop. `check-types` and `dev` depend on `^build`.
- **Built vs JIT:** `@repo/contracts` is built (`tsc` → `dist/`). Not JIT. Not in `transpilePackages`. JIT for Next: `@repo/ui`, `@repo/api-client`.
- **Install:** `pnpm add` / `--filter` / `-w`. Latest stable unless already pinned. Never hand-edit versions.
- **Imports:** static only. The call site names the contract. Env is `@repo/db/env`, not `@repo/db`. Contracts from `@repo/contracts` at the call site — no redefine, no re-export. API: `@api/…` + `.js` (no `../`). Groups: side-effect → external → workspace → `@api/…`. Inline `import type` on a shared module. Next: `@/*`. `api-client`: bundler, no `.js` on relatives.
- **No comments in source.** Put rules here or in `.env.example`.
- **Docker:** agents do not run Compose unless asked. `apps/api/.env.local`. Postgres-only: `pnpm docker:postgres`. API in Compose: `pnpm docker:up` (runner) | `pnpm docker:dev` (watch target + `--watch --build`). `pnpm docker:down` | `docker:logs` | `docker:ps`. Container entrypoint migrates when `RUN_DB_MIGRATE=true` (default); empty DB also runs `pnpm db:seed`.
- API: Express 5, tRPC v11 `/api/trpc` `v1.*`, thin `modules/*/`, no Express in tRPC context, `AppRouter` from `@repo/api/trpc`, `@api/*` → `apps/api/src/*`.
- Zod 4: `z.url()`, `z.iso.datetime()`.
- Client: `@repo/api-client`. `NEXT_PUBLIC_API_URL` required; Next rewrites `/api/:path*`.
- Better Auth `/api/auth/*` before `express.json`. Identity only; authz in procedure guards.
- Env: `requireEnv` / required `NEXT_PUBLIC_*`. `.env.local` then `.env` (neither overrides already-set process env — Compose `DATABASE_URL` wins in the API container). Copy `.env.example` → `.env.local`.
- Root does not call Accounts/Shop/Support mutations.
- DB: Drizzle + Postgres. `packages/db` by owner. One database is not shared authority. No cross-domain joins. Support stores owned copies of customer and order text, never Shop or Accounts tables. Domain rows are server state, not in-memory fixtures. `pnpm db:generate` then `pnpm db:migrate`. No `db:push` without explicit consent. No ad-hoc SQL. Empty `returning` is not success. Auth seed: `pnpm db:seed`. Provider seed: `pnpm db:seed:providers`. Do not run provider seed unless asked.
- Queries: filters in SQL `WHERE`. One round-trip. One JS pass (`flatMap` / `for…of`), not `.filter().map()`. Readable names. `Pick` / `Omit` / `z.infer`.
- **Props:** Omit `className` unless a caller passes it. Then extend `ComponentProps` of that element (or `Pick` `className`). Never invent `className` or extra `children` on `ComponentProps`. `PropsWithChildren` only when the base type has no children.
- **Commit:** Layout effects run inside-out. A child's layout effect runs before the parent host ref is filled; the parent node is already in the DOM. Do not read a parent ref there. Measure from this node's ref or the DOM parent. A layout effect does not beat the first HTML paint.
- **Motion:** A known first-paint rest is CSS on one fixed origin. Gesture, snap, and resize are offsets from that origin. Do not switch the origin; that redefines the offset and jumps. Do not pin first paint with JS. Open, close, and yellow minimize pour one temporary presentation into the existing Dock mark while the live document keeps its stage geometry; restore reverses it, and reduced motion is instant. Green fullscreen stays instant, including yellow minimize and restore from that fill.
- **Presence:** Keep exiting geometry long enough for the parent to interpolate size from one fixed layout anchor. Exit one presentation snapshot together. Brief state gaps preserve the surface; only sustained absence collapses it.
- **Scale:** `@repo/ui`. Headings `text-3xl`. Body `text-base`. Labels `@repo/ui/label`. Controls `h-8`. Buttons `rounded-3xl` and hug the label. Primary or destructive; no outline; ghost only with a visible gray hover. Heroicons `24/outline`. `data-app` remaps `primary`. Root is a Mac desktop: full-viewport canvas, pinned Dock, persistent independent provider windows, one workflow status that rests as a Root mark, grows a pill while work runs, turns red on failure, and springs to the nearest canvas corner. Steal spatial rules, not Apple chrome. Green fills the canvas; green again restores. A window may hang off the canvas and sit under the Dock; the titlebar stays grabable. Dock marks grow out of the shelf; the tray does not swell with them. A Dock click rests magnification; pointer movement resumes it. The app library owns providers; the Dock owns ordered references. Builtin providers mount. Child pages are a dark canvas in that hue, not the ink fill. Inter sans; Geist Mono for `font-mono`.
- **Workflow:** Prepare freezes an allowlisted read graph. It refuses illegal tools and arguments, not useful length. Repeats of an allowlisted read are legal. The step cap is a safety ceiling, independent of how many children or tool names exist. Execute opens or reuses each provider window, rediscovers, and invokes each step on that live document without closing the others. Do not add a per-app prepare function. Custom invoke is a separate Root tool on a human grant; it never enters pass evidence.
- **Validation:** Validate once when untrusted data crosses a boundary, retain the typed value, preserve byte limits before JSON parsing, and measure before adding validation caches.
