# Demo — 3 minutes

Read this once. Do not narrate the file. Chrome with WebMCP, signed in, inspect open. Settings → Typing and Before it clicks → Slow, so fill and Search hold on camera. Seed is already there: Lin Park, Silent Mouse, Ada Ortega, her USB-C hub case.

Skip Lab, notifications, and custom grants. They will eat the clock.

---

## 0:00–0:40 — Why this exists

WebMCP in one line: the browser exposes tools on a live page so an agent can do work there. Agents are already strong. What they cannot do is act on a real site unless that site hands them tools.

Building one new app full of tools is the obvious path. Root is the other path. Several real apps stay themselves. Root sits in the middle.

---

## 0:40–1:00 — Root

Root is the desktop. Catalog, Customers, and Cases are providers: real sites in their own windows. Root is the orchestrator. It prepares a graph, opens or reuses those windows, and runs tools on the live documents. It does not scrape the page.

If Root rejects a graph, the agent never runs it. If Root pauses for you, the harness waits or times out. That pause is the approval. A row click, a write you persist, or Take control.

Then show it.
